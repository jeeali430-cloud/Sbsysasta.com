# Sbsysasta.com

Premium home appliances & electronics e-commerce for Lahore, Pakistan.

## Stack
Next.js 14 (App Router) · TypeScript · Tailwind CSS · Supabase (Step 7)

## Local dev
```bash
npm install
cp .env.example .env.local
npm run dev
```
Open http://localhost:3000
